# ZCode 气泡主题（zcode-bubble-theme）

给 [ZCode](https://z.ai) 桌面客户端打本地样式补丁，把对话里**你自己发的消息**变成网页版同款的浅蓝色圆角气泡，支持深色模式。装上/还原各是一个按钮，随时可退。

> 改动只在 CSS 样式层，不动任何功能逻辑。

## 效果

| 官方原版 | 安装后 |
|---|---|
| 用户消息为右侧纯文本 | 用户消息为右侧浅蓝圆角气泡（`#dbe9fd`，无边框，16px 圆角） |

（深色模式下自动换成深蓝底色）

## 使用方法

前提：Windows 10/11、已安装 [Node.js](https://nodejs.org)（18 或更高）、已安装 ZCode 桌面版。

1. **完全退出 ZCode**（右下角托盘图标也要右键退出）
2. 下载/克隆本仓库到本地任意目录
3. 双击 **`安装气泡版.bat`** → 按 Y → 等待「成功」
4. 打开 ZCode 看效果

不喜欢随时双击 **`还原原版.bat`** 回到官方界面。

## 原理

1. 解包本机已安装的 `resources/app.asar`（不改原文件，先做备份）
2. 在渲染层样式表末尾追加一小段覆盖 CSS（有标记、可幂等重装）
3. 重新打包替换，原版 asar 自动备份为 `app.asar.original-backup.asar`
4. 「还原原版」用备份把原文件放回去

**注意**：

- ZCode **自动更新后补丁会被官方文件覆盖**，重跑一次「安装气泡版.bat」即可
- 安装失败会自动回滚，不会留下打不开的 ZCode
- 若 ZCode 大版本更新导致界面结构变化，补丁可能失效或被跳过（脚本会提示），等更新适配

## 目录说明

```
install-core.cjs     安装/还原核心脚本（node install-core.cjs install|restore|dryrun）
bubble.css           主题样式定稿
安装气泡版.bat        一键安装（自动装 npm 依赖）
还原原版.bat          一键还原
package.json         依赖声明（@electron/asar）
```

默认针对 ZCode 安装在 `D:\Zcode` 的情况；装在别处时设置环境变量 `ZCODE_RES_DIR` 指向其 `resources` 目录即可。
